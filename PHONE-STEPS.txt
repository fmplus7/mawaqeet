معاينة كاملة من الجوال فقط (بدون حاسوب)
==========================================
الفكرة: ترفع هذه الملفات إلى GitHub، ثم يبني Netlify الموقع في السحابة
وينزّل مدن العالم والمصحف تلقائياً، ويعطيك رابطاً تفتحه من جوالك.
الحسابات مجانية.

1) فك الضغط
   - آيفون: تطبيق «الملفات» ← اضغط على ملف ZIP ← يظهر مجلد.
   - أندرويد: تطبيق «الملفات» ← اضغط مطولاً على ZIP ← استخراج.

2) GitHub (المستودع)
   - افتح github.com من متصفح الجوال وأنشئ حساباً.
   - New repository ← الاسم: mawaqeet ← Public ← Create repository.
   - اضغط الرابط «uploading an existing file».
   - اختر كل الملفات التسعة من المجلد (index.html و sw.js و manifest.webmanifest
     و icon-192.png و icon-512.png و package.json و netlify.toml
     و build-data.mjs و PHONE-STEPS.txt) ثم اضغط Commit changes.
   - يجب أن تظهر الملفات في الصفحة الرئيسية للمستودع (بدون مجلدات).

3) Netlify (الاستضافة)
   - افتح netlify.com ← Sign up ← Continue with GitHub.
   - Add new site ← Import an existing project ← GitHub ← اختر mawaqeet.
   - اترك الإعدادات كما هي (تُقرأ من netlify.toml) ← Deploy.
   - انتظر 3 إلى 8 دقائق. عند النجاح يظهر رابط مثل xxxx.netlify.app.

4) افتح الرابط من جوالك
   - المواقيت والقبلة تعمل مباشرة، ومن زر المدينة تبحث في مدن العالم.
   - تبويب «القرآن» يظهر فيه المصحف إذا نجح التنزيل.
   - لتثبيته كتطبيق: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية
     (Chrome أندرويد ← القائمة ← تثبيت التطبيق).

5) إن لم يظهر المصحف أو البحث عن المدن
   - في Netlify افتح Deploys ← آخر عملية ← Deploy log.
   - ابحث عن سطر يبدأ بـ ⚠️ «تخطّيت جزءاً» وأرسل لي نصه لأصلحه.
   - الموقع يُنشر حتى لو فشل المصحف، وتظهر فيه رسالة بدلاً منه.

تنبيه: المصحف تجريبي، ولا تنشر الموقع علناً أو في المتجر قبل إذن
مجمع الملك فهد (انظر README في الحزمة الكاملة).
